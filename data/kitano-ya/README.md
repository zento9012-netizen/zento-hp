# お食事処 北の屋

このフォルダは北の屋の店舗HP素材置き場です。

## 写真の入れ方

店舗から掲載許可を得た写真を以下のファイル名で追加すると、`data/store.js` の画像設定から差し替えできます。

- `hero.jpg` — ファーストビュー
- `feature-1.jpg` — こだわり1
- `feature-2.jpg` — こだわり2
- `feature-3.jpg` — こだわり3
- `gallery-1.jpg` ～ `gallery-4.jpg` — ギャラリー

現時点では写真未投入です。画像がない状態でもHPのレイアウトが崩れないよう、テンプレート側にフォールバックを用意しています。

## 注意

店舗から掲載許可を得た素材のみ配置してください。第三者サイトから無断転載した画像は使用しません。
