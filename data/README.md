# 店舗HPデータ運用

このフォルダの店舗データは、`store.js` を元に店舗ごとの情報を管理するための領域です。

## 運用方針
- ヒアリングシートの回答を店舗データへ変換する
- 店舗固有の文章・メニュー・営業時間・連絡先・SNS・LINE等をデータとして分離する
- `store-template.html` は共通テンプレートとして維持し、店舗情報を直接HTMLへ書き込まない
- 実データがない項目は推測せず、空欄または未設定として扱う
- 公開前に住所・電話番号・営業時間・料金・URL・画像を確認する

## 店舗追加時の基本手順
1. ヒアリングシートから情報を整理
2. 店舗データを作成
3. 画像を店舗フォルダへ配置
4. テンプレートにデータを接続
5. プレビューで確認
6. `main` に反映
7. Cloudflare Workers の自動デプロイを確認

このREADMEは運用ルールの土台です。
