# ZENTO HP

ZENTOの本番ブランドサイトと、店舗・飲食店向けHP制作テンプレートを管理するリポジトリです。

## 公開ルート

- ZENTO本番ブランドサイト: `index.html`
- 公開先: Cloudflare Workers
- 本番URL: `https://still-base-7db3.zento9012.workers.dev/`
- GitHub Pagesは使用しません

## 構成

- `index.html` — ZENTO本番ブランドページ
- `data/zento.js` — ZENTO本番ページの表示内容
- `store-template.html` — 店舗・飲食店向けHPテンプレート
- `data/store.js` — 店舗HPの差し替えデータ
- `images/` — 店舗HPで使用する画像を配置する場所

## ZENTO本番HPの更新

文章・キャッチコピー・サービス内容など、内容だけを変更する場合は原則として `data/zento.js` を変更します。`index.html` のデザイン・構造は原則として変更しません。

変更は `main` に入ったあと、接続済みのCloudflare Workersへ自動反映されます。本番URLやcanonical URLは変更しません。

## 店舗HP制作の基本フロー

1. ヒアリングシートから店舗情報を整理する
2. `data/store.js` に店舗情報を反映する
3. 店舗画像を配置する
4. `store-template.html` を店舗サイト用に利用する
5. 公開前チェックを行う
6. GitHubの `main` に反映し、Cloudflare Workersへデプロイする
7. 本番表示を確認する

## ヒアリングシートとの対応

ヒアリングシートにある以下の情報を店舗データへ反映します。

- 基本情報：店舗名、略称、メインキャッチコピー、サブコピー、店舗の特徴・こだわり
- こだわりポイント：3項目
- 店舗情報：住所、電話番号、営業時間、定休日、駐車場、問い合わせメール
- お知らせ：日付、タイトル、本文
- 予約・テイクアウト・決済：予約URL、対応サービス、決済方法
- SNS・求人：Instagram、X、LINE公式、求人情報
- メニュー：カテゴリ、商品名、説明、価格
- 追加コンテンツ：口コミ、スタッフ紹介、素材・産地、SNS連携、メディア掲載、Googleマップ、予約ボタン、テイクアウト・デリバリー、決済表示、多言語、FAQ、求人、プライバシーポリシー、OGP・構造化データ・favicon等

ヒアリングシート上で選択された追加項目だけを対象店舗HPへ反映する方針です。

## 公開前チェック

- プレースホルダー（`【...】`、`info@example.com`、`00-0000-0000`等）が残っていない
- 店舗名・住所・電話番号・営業時間・定休日が正しい
- メニュー名・価格が正しい
- 画像パスと画像表示を確認
- Google Maps URLを確認
- メールアドレス・SNS URLを確認
- canonical / sitemap / robots.txtを確認
- スマートフォン表示を確認
- お問い合わせ・電話・予約リンクを確認

## 運用ルール

- 本番ブランドHPと店舗HPテンプレートを混同しない
- 本番URLを勝手に変更しない
- SEO設定を変更するときは既存のインデックス状況を考慮する
- 店舗固有情報はデータ側に集約し、HTML構造を直接書き換える作業を減らす
- 実店舗公開時は、ヒアリングシートにない情報を推測で追加しない
