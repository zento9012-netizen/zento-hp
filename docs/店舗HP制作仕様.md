# ZENTO 店舗HP制作仕様

## 目的

飲食店・店舗向けHPを、ヒアリングシートの回答をもとに同一テンプレートへ反映するための制作基準。

## 入力元

原則として、ユーザーから受け取ったヒアリングシートを一次情報とする。ヒアリングシートに記載がない情報は、実例として勝手に補完しない。

## 基本情報

- 店舗名
- 屋号の略称・愛称
- メインキャッチコピー
- サブコピー
- お店の特徴・こだわり（2〜3行）

## こだわりポイント

3項目を基本とする。

- タイトル
- 説明

## 店舗情報（アクセス）

- 住所
- 電話番号
- 営業時間
- 定休日
- 駐車場
- お問い合わせ用メールアドレス

## お知らせ

必要なものだけ掲載する。

- 日付
- お知らせ内容

## 予約・テイクアウト・決済

回答がある場合に反映する。

- オンライン予約サイト名・URL
- テイクアウト・デリバリー対応（Uber Eats、出前館、foodpanda、Wolt、店頭テイクアウトのみ、その他、対応なし）
- 決済方法（現金、クレジットカード、交通系IC、QRコード決済、その他）

## SNS・求人

- Instagram
- X（Twitter）
- LINE公式
- 求人情報（募集職種・時給）

## メニュー

カテゴリと商品を整理する。

- カテゴリ
- 商品名
- 説明
- 価格

カテゴリ数・商品数は店舗に合わせて増減可能とする。

## 追加コンテンツ

ヒアリングシートで使用が選択された項目だけを反映する。

- お客様の声・口コミ
- スタッフ紹介
- こだわりの素材・産地紹介
- SNS連携
- メディア掲載・実績
- Googleマップ埋め込み
- オンライン予約ボタン
- テイクアウト・デリバリー表示
- 決済方法アイコン表示
- 多言語切り替え
- よくある質問（FAQ）
- 求人情報
- プライバシーポリシー本文
- OGP・構造化データ・favicon設定

## 制作ルール

1. 店舗固有情報はデータ側にまとめる。
2. デザイン・テンプレートと店舗データを分離する。
3. ヒアリングシートにない事実を勝手に作らない。
4. プレースホルダーを残したまま実店舗サイトを公開しない。
5. 本番ブランドHP（ZENTO）と店舗HPを混同しない。
6. ZENTO本番URLを変更しない。
7. 公開前に電話、メール、予約、地図、SNS、画像、メニュー、営業時間等を確認する。

## 自動化の考え方

将来的な標準フローは以下とする。

ヒアリングシート
→ 店舗データ整理
→ `data/store.js` 等へ反映
→ 店舗テンプレートへ反映
→ GitHub `main` へ反映
→ Cloudflare Workersへデプロイ
→ 本番表示確認
